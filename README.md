# Сайт Инны Сибиль — ведущая мероприятий, Москва

Одностраничный сайт личного бренда. Тёмная база, белая типографика, лаймовый акцент
взят из костюма на фотографиях. Все эффекты написаны вручную: внешних библиотек нет,
интернет нужен только для подгрузки шрифтов Google Fonts (без них сайт работает на
системных шрифтах).

## Как открыть

**Основной способ — локальный сервер.** Так сайт и проверялся:

```
start.bat
```

или вручную:

```
node tools/serve.js 5173
```

Затем откройте http://localhost:5173

Двойной клик по `index.html` тоже должен работать: фотографии зашиты в `js/assets.js`
как data-URI, а скрипты подключены обычными тегами, без модулей. Этот способ не
проверялся, поэтому при странностях запускайте через `start.bat`.

## Структура

```
index.html          разметка и весь текст
css/style.css       дизайн-система и все стили
js/assets.js        фотографии в base64 (генерируется, вручную не править)
js/core.js          инерционный скролл, тикер, наблюдатель за секциями
js/gl.js            мини-слой над WebGL: шейдерные плоскости и облако точек
js/shaders.js       GLSL: фоновая дымка, портрет, морфинг-слайдер
js/scenes.js        связь шейдерных сцен со скроллом
js/ui.js            разбивка заголовков, курсор, карусели, аккордеон, форма
js/main.js          порядок запуска
img/                исходные фотографии
tools/build-assets.js  пересборка js/assets.js
tools/serve.js         локальный сервер
```

## Эффекты

| Где | Что происходит |
|---|---|
| Фон всей страницы | Шейдерная дымка на шуме, реагирует на скролл и курсор |
| Первый экран | Портрет в шейдере: дуотон, дисторсия от курсора, аберрация от скорости скролла |
| Секция «Кадры» | Закреплённый экран, четыре кадра перетекают друг в друга жидкой маской |
| Секция «Один вечер» | Портрет, собранный из тысяч светящихся точек; собирается и распадается по скроллу |
| Заголовки | Появляются по словам из-под маски |
| Карточки и отзывы | Горизонтальные карусели с перетаскиванием и выбегом |
| Курсор | Кастомный курсор с притяжением к кнопкам |

Сайт корректно деградирует: без WebGL показываются обычные фотографии, при системной
настройке «уменьшить движение» анимации отключаются, на телефонах используется
нативный скролл.

## Что нужно заменить перед запуском

Все заглушки помечены в тексте лаймовым пунктиром или бейджем «плейсхолдер».

1. **Телефон и почта** — сейчас `+7 000 000-00-00` и `почта@пример.ru`
   (в шапке меню, в блоке контактов и в подвале).
2. **Цены** в карточках форматов — сейчас `00 000 ₽` в восьми карточках.
3. **Цифры в блоке статистики** — 10 лет, 600+ мероприятий, 92% по рекомендации.
   Подтвердить у Инны, иначе убрать.
4. **Год начала работы** — в тексте «о себе» стоит 2015.
5. **Отзывы** — пять карточек-заготовок, нужны реальные тексты, имена и даты.
6. **Фотографии с мероприятий** — сейчас во всех сценах используются четыре
   портретных снимка. Живые кадры с площадок сильно усилят секцию «Кадры».
7. **Ответы в FAQ** — про предоплату, длительность банкета, технику и выезды
   согласовать с Инной.
8. **Отправка формы** — сейчас форма проверяет поля и показывает сообщение,
   но никуда не отправляет. Нужно подключить бота в Telegram или почтовый сервис.
9. **Реквизиты и политика обработки данных** — в подвале заглушка.

## Как добавить или заменить фотографии

1. Положите файлы в `img/` (имена латиницей, например `event-01.jpg`).
2. Выполните `node tools/build-assets.js` — обновится `js/assets.js`.
3. Пропишите новые ключи в `js/scenes.js`: массив `keys` в `initReel` и параметр
   `image` в `initParticles`. Ключ — имя файла без расширения.

Для облака точек лучше всего подходят снимки на однородном светлом фоне: фон
отсекается автоматически по насыщенности цвета.
